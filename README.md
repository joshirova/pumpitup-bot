# PumpItUp — Рекомендательная фитнес-система на базе машинного обучения

> **Выпускная квалификационная работа бакалавра**  
> Автор: Оширова Юлия Николаевна (НФИбд-01-22)  
> РУДН, 2026 г. | Научный руководитель: Молодченков А.И., к.ф.-м.н.

Telegram-бот, формирующий персонализированные тренировочные циклы с учётом антропометрии, уровня подготовки, травм и хронических заболеваний. Система построена на сравнительном анализе моделей **Learning to Rank** и интегрирует лучшую модель — **XGBoost rank:ndcg** (NDCG@3 = 0,9987) — в трёхуровневую production-архитектуру.

---

## 🎯 Научная новизна

- **Первое сопоставление** трёх парадигм Learning to Rank (pointwise, pairwise, listwise) для задачи подбора фитнес-планов в едином экспериментальном протоколе.
- **Градуированная релевантность** r ∈ {0, 1, 2, 3} на основе детерминированных правил ВОЗ и ACSM вместо классической бинарной разметки.
- **Расширенный набор признаков** — 15 параметров, включая три новых клинически значимых: `injury_history`, `weekly_frequency`, `activity_level`.
- **SHAP-анализ интерпретируемости** и абляционное исследование с соотнесением иерархии важности с клиническими руководствами (FITT-принцип ACSM).
- **Эмпирическое подтверждение** неприменимости коллаборативной фильтрации при холодном старте (NDCG@3 Matrix Factorization = 0,142).

## 🏗️ Архитектура системы

Бот реализован по принципу **разделения ответственности** (separation of concerns). Каждый модуль решает одну задачу.

### Трёхуровневая рекомендательная система

```
┌─────────────────────────────────────────────────────────────┐
│  Уровень 1 — ML-ранжирование тренировочных планов           │
│  RankingService (logic/ml/ranking_service.py)               │
│  • XGBoost rank:ndcg ранжирует 60 шаблонных планов          │
│  • Safety-фильтр is_plan_contraindicated по протоколам ACSM  │
│  • Жадный выбор разнообразия по модальности (modality)     │
├─────────────────────────────────────────────────────────────┤
│  Уровень 2 — ML-регрессор персональной нагрузки            │
│  LoadRegressor (logic/ml/load_regressor.py)                 │
│  • MLPRegressor (32→16 нейронов, ReLU)                     │
│  • Предсказывает: sets, reps, rest_sec, RPE                 │
│  • R² = 0,957 на синтетических данных NSCA                  │
│  • Целевая ЧСС по формуле Танаки: HRmax = 208 − 0,7·age     │
├─────────────────────────────────────────────────────────────┤
│  Уровень 3 — Rule-based селектор упражнений                 │
│  ExerciseSelector (logic/exercise_selector.py)               │
│  • Каскадный фильтр из 873 упражнений Free Exercise DB      │
│  • 3 ступени: строгий → ослабленный → расширенный          │
│  • Безопасные правила (травмы, мед. протоколы) никогда     │
│    не ослабляются — принцип fail-closed                     │
└─────────────────────────────────────────────────────────────┘
         ↑
    RecommendationService (Singleton-оркестратор)
    CycleBuilder — последовательный вызов L1→L2→L3
```

## 🔬 Интерпретация и абляция

**SHAP-анализ** (топ-4 признака):  
1. `intensity` (2,127) — интенсивность плана  
2. `weekly_frequency` (0,719) — желаемая частота тренировок  
3. `modality` (0,667) — модальность нагрузки  
4. `level` (0,491) — уровень подготовки  

Иерархия совпадает с FITT-принципом ACSM — подтверждение гипотезы H3.

**Абляционное исследование** (падение NDCG@3 при исключении):
- `equipment` (план): −17,2 %
- `equipment_pref`: −15,0 %
- `modality`: −14,7 %
- `weekly_frequency`: −12,0 %
- `level`: −6,2 %
- `intensity`: −5,7 %

## 🚀 Установка и запуск

### Требования
- Python 3.11+
- pip

### 1. Клонирование
```bash
git clone https://github.com/joshirova/pumpitup-bot.git
cd pumpitup-bot
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

Основные библиотеки: `python-telegram-bot 21.6`, `XGBoost 2.0.3`, `scikit-learn 1.4.2`, `pandas 2.2.2`, `numpy 1.26.4`, `shap`.

### 3. Настройка окружения
```bash
cp .env.example .env
```
Отредактируй `.env`:
```env
TELEGRAM_TOKEN=your_bot_token_from_BotFather
```

### 4. Запуск
```bash
python bot.py
```

## 💬 Пользовательский сценарий

1. Отправьте `/start` в Telegram.
2. Пройдите **13-шаговый опросник**:
   - Пол, возраст, рост, вес, % жира
   - Уровень подготовки, повседневная активность
   - Желаемая частота тренировок (2–5 раз/нед)
   - Оборудование (дом / зал)
   - Длительность цикла (1–3 недели)
   - Травмы (колено / спина / плечо / нет / несколько)
   - Хронические состояния (мультивыбор из 6: ожирение, гипертония, тахикардия, диабет 2 типа, боли в спине, травмы коленей)
   - Цель (похудение / набор массы / поддержание)
3. Получите **тренировочный цикл** с подробным описанием каждой тренировки:
   - Модальность, длительность, интенсивность (RPE), целевая ЧСС
   - Подходы, повторения, отдых
   - Список из 5–8 упражнений с мышечными группами и инструкциями
